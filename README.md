Vacancy Parser - Парсер вакансий с HH.ru
Простая программа для поиска и анализа вакансий с сайта hh.ru. Помогает найти подходящие вакансии, отфильтровать их по зарплате и сохранить результаты.

Что умеет программа:
🔍 Искать вакансии на hh.ru по ключевым словам

💰 Показывать вакансии с самой высокой зарплатой

📝 Фильтровать вакансии по описанию

💾 Сохранять результаты в JSON-файл

🗑️ Удалять ненужные вакансии

📊 Сравнивать вакансии по зарплате
